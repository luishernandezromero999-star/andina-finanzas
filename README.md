# Dashboard Financiero - Distribuciones Andina Comercial S.A.S.

Aplicación de analítica y visualización financiera desarrollada en **Python** y **Streamlit** con gráficos interactivos en **Plotly**. Diseñada para realizar diagnósticos estratégicos y financieros integrales, análisis de capital de trabajo, descomposición DuPont y evaluación de creación de valor (EVA y Flujo de Efectivo Libre).

## 🚀 Características Principales

- **Visión Global y Trayectoria (2021-2025):** Evolución de ventas, EBITDA, estructura de activos y utilidad neta.
- **Liquidez y Solvencia:** Razón corriente, prueba ácida y análisis de capital de trabajo frente a benchmarks del sector.
- **Eficiencia y Ciclo de Conversión de Efectivo (CCE):** Días de inventario (EPI), días de cobro (PPC), días de pago a proveedores (PPP) y rotaciones operativas.
- **Endeudamiento y Apalancamiento:** Estructura de deuda vs patrimonio y cobertura de gastos financieros (RCI).
- **Rentabilidad y Márgenes:** Análisis de márgenes EBITDA, operacional, neto y gráfico tipo cascada (*Waterfall*).
- **Descomposición DuPont (3 factores):** Desglose del ROE en margen neto, rotación de activos y multiplicador de apalancamiento.
- **Creación de Valor Económico:** Spread ROIC vs WACC, cálculo del EVA y Flujo de Efectivo Libre (FEL).
- **Simulador Gerencial Interactivo:** Análisis de sensibilidad tipo *What-If* para evaluar políticas comerciales y de inventario.

## 🛠️ Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/luishernandezromero999-star/andina-finanzas.git
   cd andina-finanzas
   ```

2. **Instalar dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Ejecutar la aplicación:**
   ```bash
   streamlit run app.py
   ```

4. **Abrir en el navegador:**
   La aplicación se abrirá automáticamente en `http://localhost:8501`.
